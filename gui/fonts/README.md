# Bundled fonts

These `.ttf` files are embedded directly into `capture_bypass_gui.exe` at compile
time via `include_bytes!` in `src/theme.rs`. No runtime files are shipped.

## Bundled

| File | Role | License |
|---|---|---|
| `IBMPlexMono-Regular.ttf` | Monospace family (PIDs, stats, badges, labels) | OFL 1.1 (`OFL.txt`) |
| `IBMPlexMono-Bold.ttf` | Monospace bold | OFL 1.1 |
| `IBMPlexSans-Regular.ttf` | Proportional / UI text | OFL 1.1 |
| `IBMPlexSans-Medium.ttf` | Proportional medium weight | OFL 1.1 |
| `IBMPlexSans-SemiBold.ttf` | Proportional semi-bold | OFL 1.1 |
